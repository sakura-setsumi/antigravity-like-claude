# 任务进度与过程透明化规范（task-hud）

1. **执行中展示「小总结 + 工具链 + 底部任务面板」，完成后自动收起只保留最终总结**：
   - **禁止**输出 `> 📋 ...` Markdown 任务列表，**禁止**手动 `read_file` / `edit_file` 修改 `task-hud*.html`（面板 HTML 由组件后端原子维护，对模型为黑盒），也**严禁在同一次回答中输出 2 个及以上 `<agent-embed>` 标签**。
   - 当收到需要 **2 个及以上步骤** 才能完成的任务时，通过极简 JSON 组件工具 `task_hud_init` 与 `task_hud_check` 驱动面板：
     1. **第 1 步（初始化任务组件，收到返回值后输出唯一 1 次 `<agent-embed>`）**：
        - 调用 `task_hud_init`，传入简洁 JSON（任务数组直接传字符串即可，后端自动按 `"1"`, `"2"`, ... 编号并将第 1 项设为进行中、自动分配本轮隔离槽位 `task-hud-t<K>.html`）：
          ```json
          { "title": "任务标题", "tasks": ["步骤一", "步骤二", "步骤三"], "log": "第一步简短说明（关键文件名/命令用反引号标出）" }
          ```
        - `task_hud_init` 会返回本轮专属的 `<agent-embed src="file:///.../task-hud-t<K>.html"></agent-embed>`。在紧接着的回复中**原样且仅输出这一次 `<agent-embed>`**（标签外不要写过程文字），**并在同一步响应中立即发起至少 1 个业务工具调用**（严禁只输出 `<agent-embed>` 而不调用任何工具，否则宿主会误判为结束）。
     2. **中间每一步（仅传极简 JSON 勾选完成 + 追加小总结，聊天框外不输出过程文字）**：
        - 在最终总结之前的**所有中间步骤**（含等待后台命令/定时器唤醒时），**严禁在聊天框外输出任何过程文字或等待提示**；等待后台任务时直接空文本结束本步即可。
        - 完成某项任务时，调用 `task_hud_check` 只需给对应 `id` 传 `done: true`（后端自动推进下一项为进行中，并将 `log` 与已完成的 `Thought for Xs ›` / 工具链穿插渲染在任务栏上方，任务栏始终固定在最底部）：
          ```json
          { "id": "1", "done": true, "log": "已完成第一步，正在执行下一步..." }
          ```
        - 也支持仅传 `{ "log": "..." }` 追加阶段说明，或批量勾选 `{ "checks": { "1": true, "2": true }, "log": "..." }`；在全部验证完成前，至少保留最后一项未勾选以保持面板展开。
     3. **会话完成收尾（一键收起过程面板，只保留最终总结）**：
        - 当所有修改与验证均已完成、准备结束本轮会话时：
          a) 在最后一次工具调用中调用 `task_hud_check({ "all_done": true, "log": "可选收尾说明" })`（或勾选最后一项 `done: true`），组件会自动冻结并折叠为一行完成条；
          b) 紧接着在**最后一轮纯文本回复**中，直接输出清晰完整的**最终总结**（切勿再次输出 `<agent-embed>`）。
2. **保持低开销**：简单问答或单步查询无需调用 `task_hud_init` / `task_hud_check`，也无需嵌入面板。
3. **只读模式（`Plan mode` / `Orchestrator`）与 Hook 自动兜底规范**：
   - 若处于只读规划模式或当前环境暂未加载 `task_hud_init` / `task_hud_check` 工具，**不要尝试绕过限制或手动编辑 `task-hud*.html`**；收到需要 **2 个及以上步骤** 的任务时，按以下流程执行：
     1. **第 1 步主动嵌入唯一 1 次 `<agent-embed>` 并同时发起只读工具调用**：顺延选定本轮文件名 `task-hud-t<K>.html`（首次为 `task-hud-t1.html`，之后递增），直接输出 `<agent-embed src="file:///<Artifact Directory Path>/task-hud-t<K>.html"></agent-embed>`（标签外不写过程文字）并在同一步发起至少 1 个只读工具调用，Hook 会自动初始化默认任务、工具链与实时计时。
     2. **中间步骤保持聊天流干净**：不在聊天框外散落过程文字，执行 `run_command` 时填好 `toolSummary`。
     3. **收尾或移交执行（`exit_plan_mode`）**：
        - 纯排查/问答：最后一轮直接输出最终结论，`Stop` Hook 会自动收起面板；
        - 调用 `exit_plan_mode` 移交执行：在 `plan` 中注明“本轮已挂载面板 `task-hud-t<K>.html`，执行阶段**切勿再输出新的 `<agent-embed>`**，请直接调用 `task_hud_init` / `task_hud_check` 更新任务与进展，完成后传 `all_done: true` 再输出最终总结”。
   - **Hook 自动兜底提醒衔接**：若收到 Hook 系统消息提示某槽位 `task-hud-t<K>.html` 已就绪但尚未嵌入，后续仍需调用工具时在下一轮补发唯一一次该 `<agent-embed>` 并同时发起业务工具调用；若已准备直接给出最终回答则无需再嵌入。
